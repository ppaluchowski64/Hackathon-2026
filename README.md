# Hackathon-2026
This game is made for Hackathon 2026

Gotowa wersja do pobrania na Windows i Android choć obecna konfiguracja wspiera też Linux, macOS, i iOS. Załączona wersja to wersja single player ze względu na problemy z usługą Oracle Cloud, ale na branchu multiplayer jest pełna wersja gry w tej postaci :)

Grę można pobrać w sekcji Releases w postaci plików, których nie trzeba instalować: https://github.com/ppaluchowski64/Hackathon-2026/releases

Sterowanie myszką, używanie powerup-ów prawym przyciskiem. Co do wersji na telefon to oczywiście palec do poruszania się i przycisk do powerup-ów
